# OpsPilot

AI-assisted field operation - report, assign, resolve, sync offline.

## Stack

SwiftUI · SwiftData · Node 24 · TypeScript · Hono · PostgreSQL · AWS Lambda/CDK · React

## Layout

- `ios/` - iPhone app (SwiftUI)
- `api/` - HTTP API (Node/TypeScript/Hono)
- `web/` - Manager dashboard (React)
- `infra/` - AWS CDK (Lambda + SSM)
- `docs/` - Architecture, ADRs, system design notes
